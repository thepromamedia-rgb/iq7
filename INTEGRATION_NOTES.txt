CREDITS-ONLY GAME ZONE

This build uses virtual, non-redeemable credits. Credits have no cash value. There are no deposits, withdrawals, cash prizes, or cash-outs. Server endpoints for payment and payout return 403 by default. Only an authenticated admin can add credits from Admin > Users > Add Credit; each credit requires a reason and is audited.

Games: Coin Flip, Dice Roll, Lucky Number, Rock Paper Scissors, and Aviator-style multiplier game. Stakes and outcomes are validated/settled on the server. Game results are logged. Outcomes are for entertainment/testing only.

Run: double-click start.bat on Windows, or ./start.sh on Mac/Linux. Open http://localhost:3000. Do not open index.html directly. Run `npm test` for regression tests.

Keep CREDITS_ONLY enabled (the default). Do not use real-money payment or payout flows in this build.
