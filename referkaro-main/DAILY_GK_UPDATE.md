# Daily unique GK questions

- Admin Daily Task editor now pre-fills two Hindi general-knowledge questions for each selected date.
- The question bank contains 20 questions; the date determines a different pair for each day across the rotation.
- Each question has three options and a correct answer preselected. Admin can edit questions/options/answer and Save / Publish.
- Existing three link fields and the 10-second link completion behavior are unchanged.
- No AI key is needed for the prefilled GK bank. Optional AI generation still requires server-side provider settings.
- Validation: `npm test` passed (syntax checks and existing smoke tests). Live Hostinger/Supabase not tested.
